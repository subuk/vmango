Your own personal IaaS cloud.

Vmango turns your libvirt hosts into a small, self-hosted cloud. Choose a cloud image and instance type, add your SSH keys and launch it from your browser.

Read the documentation Quick start →

Manage the machines you launch

  • Create, start, stop and reboot virtual machines through libvirt.
  • Provision from cloud images with SSH keys and cloud-init userdata.
  • Create, clone, resize and attach storage volumes.
  • Access serial and VNC consoles in the browser.
  • Manage virtual machines across multiple local or remote libvirt hosts from one web interface.

Linux with QEMU/KVM is the main target. Local development on macOS is also possible with QEMU/HVF.

A clear view of your cloud

See machine states, allocated resources and IP addresses together. Filter by host or state, then open a machine to inspect its configuration or connect to its console.

See how machine creation works

Select an image, availability zone and instance type. CPU, memory and boot disk size are shown before you launch. Add SSH keys and cloud-init data, and Vmango chooses a suitable host in the selected zone.

Define your cloud in a config file

Define instance types and configure each host inside its cloud, including its libvirt URI, logical network and storage-class bindings.
